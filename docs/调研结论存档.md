### 需求 5 / ZDR 的核实结论

| 主张 | 结论 | 依据 |
|---|---|---|
| `data_collection: "deny"` | **OpenRouter** 的 provider routing 字段 | openrouter.ai/docs/guides/routing/provider-selection |
| `zdr: true` | 也是 **OpenRouter**，更强（只走签 ZDR 的端点） | 同上 |
| DeepSeek 官方 API | **没有**这两个参数；"不参与训练"是**账号内开关**（"数据用于优化体验"），隐私政策明确覆盖 API | cdn.deepseek.com 隐私政策 |
| Anthropic 原生 | ZDR 是**合同级**安排，不是 body 字段 | platform.claude.com 文档 |
| 结论 | 在"只支持官方"架构里加该字段是**安慰剂**；路由版必须依赖需求 3，且只能对 OpenRouter 类生效 | — |
| UI 诚实要求 | 必须写「由 X 执行，本应用无法验证服务商实际行为」，否则是假安全感 | — |
| 未知字段行为 | DeepSeek 对未知字段是忽略还是 400 → **未实测**（需 1 次真实请求） | — |
