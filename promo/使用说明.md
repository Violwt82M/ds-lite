# 小红书封面模板 · 使用说明

## 怎么用（30 秒）

1. 双击 `封面模板.html`（用 Chrome / Edge 打开）
2. 画面里**每一行字都能直接点着改**：鼠标移上去会泛蓝框，点一下就能输入
3. 改完点右上角 **「下载 PNG（2×）」** 或按 Ctrl + S
4. 得到一张 **2160×2880** 的 PNG，直接传小红书（封面按 3:4 铺满，不会裁到字）

## 工具条按钮

| 按钮 | 作用 |
|---|---|
| **A− / A＋** | 先点中某一行字，再按它调这一行的字号（长文字塞不下时缩小一档） |
| **换图标** | 换成你自己的图片（png/jpg 都行，会按圆角自动填充）；想换回来就刷新页面 |
| **还原文字** | 把字全部还原成初始文案 |
| **下载 PNG** | 导出 2160×2880 高清图 |

## 版式说明

- 尺寸固定 **1080×1440（3:4）**，正是小红书封面比例
- 结构：顶部信息行 → 大图标 → 蓝色短块 → 三行大字 → 两行说明 → 页脚
- 字体用的是系统自带的 **思源黑体（Noto Sans SC）**，粗体数字型的瑞士风，不用额外装字体
- 背景是一张纯白的 + 右上角一大片极淡的蓝（#EDF1FF），不抢字

## 改文案的建议

- 大字**只放 3 行、每行 3–4 个汉字**最有力。现在是「不限额 / 不过期 / 不续费」
- 想让"图标"更突出：把大字改短（2 行），或者按 A− 把大字缩小一档
- 说明行**别超过两行**，一行别超过 24 个字
- 别在封面上写网址和联系方式（会限流）

## 关于图标

现在封面里的图标是 CSS 画的「蓝底 + DS / Lite 白字」，和你手机上看到的桌面图标一致。
以后要是重做了 App 图标（换成真正的图形标志），点「换图标」换成新图就行，不用改代码。
