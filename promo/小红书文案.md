## 正文

先说清楚：**这不是 AI 服务，只是一个客户端。**

不含 API Key、不代理请求、没有服务器，用的是你自己的 key，所以它免费、无广告、无内购，也不碰你的聊天记录。

**为什么用 API 比开会员更舒服**

- **随用随扣**：聊多少扣多少。日常一天五十来轮大概三四毛钱，晚 9 点后和周末还打五折，没有「月度额度」绑着你
- **不限额**：没有「今日次数已用完」
- **对话不过期**：1M 上下文，一个话题能从头聊到尾，历史对话不会因为隔了太久就消失
- 模型自己挑：flash 日常，pro 啃硬活

**操作体验尽量贴原生**

多对话列表、编辑重发、重新生成、搜索、Markdown 和代码块、上下文占用随时可见。装完粘个 key 就能用，零学习成本。

**角色卡（想玩 RP 也行）**

支持导入酒馆 v2 角色卡，一份 JSON 丢进去就能用。但没堆复杂的 RP 系统，正常聊天不被打扰。

**该说的门槛**

- 得自己去开放平台注册、充几块钱、生成 key（教程在图 5）
- 装的时候会有「未验证的应用」提示，选「仍要安装」
- 数据只存本机，卸载前记得导出备份

开源在 GitHub（主页有链接），APK 在 Release 里，更新直接覆盖安装，数据不丢。
