2. 两台设备如何连接

设备 A（房主）：点「创建 Offer」→ 等 Gathering 变绿 → 复制代码块 → 发给设备 B
设备 B（加入者）：把 A 的代码块粘到下面输入框 → 点「生成 Answer」→ 等 Gathering 变绿 → 复制代码块 → 发回给 A
设备 A：把 B 的 Answer 粘到「远端 Answer」框 → 点「设置 Answer」→ 连通！
📱 局域网分享小技巧
· 微信/QQ 文件传输助手互相发代码块
· 或者一台设备截图，另一台手动打（JSON 格式，有引号有逗号，注意不要打错）
· 如果用同一个浏览器账号同步剪贴板也行
· 不要用短信：中文标点会破坏 JSON
